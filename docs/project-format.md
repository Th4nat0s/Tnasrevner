# Project format

Projects are single `.revp` ZIP files. Each archive contains `project.json` and
imported pictures under `assets/`. Metadata stores paths relative to the archive
root, making one `.revp` file sufficient to move or copy a project.

`format_version` is required. Current version is `1`.

```json
{
  "format_version": 1,
  "project_id": "uuid",
  "project_name": "Example project",
  "board_name": "Example board",
  "created_at": "2026-08-02T12:00:00+00:00",
  "updated_at": "2026-08-02T12:00:00+00:00",
  "images": [
    {"side": "top", "path": "assets/top.png", "original_name": "top.png", "pixels_per_mm": 12.5, "calibration_line": [0.1, 0.5, 0.9, 0.5], "calibration_length_mm": 40.0}
  ],
  "pads": [
    {"pad_id": "uuid", "name": "U1.1", "side": "top", "x": 0.1, "y": 0.2, "width": 0.05, "height": 0.04, "net": "GND", "device_id": "device-uuid", "number": "1", "shape": "rect", "rotation": 45.0}
  ],
  "devices": [
    {"device_id": "device-uuid", "reference": "U1", "value": "MCU", "side": "top", "x": 0.2, "y": 0.3, "rotation": 45.0, "footprint_library": "Package_QFP", "footprint_name": "LQFP-48_7x7mm_P0.5mm", "footprint_path": "assets/kicad/device-uuid.kicad_mod", "source_revision": "git-commit"}
  ],
  "display": {
    "mode": "top",
    "zoom": 1.0,
    "pan_x": 0.0,
    "pan_y": 0.0,
    "synchronized": true
  }
}
```

`images` supports zero, one top, one bottom, or one image for each side. Paths
must be relative, use `/` separators, and cannot escape the project root.
Unknown future fields are ignored when reading; unsupported format versions are
rejected explicitly.

Display mode `both` overlays the top image with the bottom image mirrored
horizontally. This is a view preference only; source images remain unchanged.
Display mode `bom` restores the bill-of-materials table.

Imported images store the normalized `calibration_line` and its exact
`calibration_length_mm`. Physical scale is recalculated from those values and the
working-image dimensions; `pixels_per_mm` remains as backwards-compatible derived
data. Older projects without the saved line/length still open, but must be
recalibrated through **Edit image** before a new KiCad device can be placed.

Pads keep a stable unique name such as `P1`. The optional `net` field assigns
electrical connectivity; pads sharing a net are connected in the workspace.
Pads generated by a KiCad device use `<reference>.<pad number>`, such as `U1.1`,
and keep the KiCad shape, rotation, device identity, and original pad number.

`devices` stores placed KiCad footprint instances and an optional BOM `value`.
Every referenced `.kicad_mod` file is copied under `assets/kicad/`, so a saved
project remains usable without the global KiCad cache or a network connection.
Older version-1 projects without `devices`, `value`, or the optional generated-pad
fields remain valid.

The ZIP is written atomically through a temporary file. Source pictures are read
and copied into the archive; original files are never modified.
